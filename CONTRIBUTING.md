# Contribuindo

1. Crie um ambiente virtual e instale `pip install -e ".[dev]"`.
2. Rode `pytest -q`, `ruff check .` e `ruff format --check .` antes de enviar a mudança.
3. Mantenha mensagens, documentação e prompts em português do Brasil; preserve o formato dos arquivos em `decisions/`.
4. Ao propor uma decisão de exemplo, use conteúdo genérico, explique contexto e alternativas, e não inclua segredos ou dados pessoais.

Pull requests pequenos, com testes para comportamento novo, são mais fáceis de revisar.
